# 🕌 Madrassa Al-Noor – Official Website

A professional website designed for **Madrassa Al-Noor**, an Islamic education institute for female students located in Khyber Pakhtunkhwa, Pakistan.

---

## 🌐 Live Website

👉 [Click here to view the website](https://rifaqajmal.github.io/madrassa-website/Madrasa-website.html)

---

## 📋 About the Project

- Designed as a **Web Development Assignment**
- Department of Computer Science, UET Mardan
- Semester 6 | Section CS

---

## ✨ Features

- Bilingual content (English & Urdu)
- Founder profile and message
- Course details (Dars-e-Nizami, 40-Day Course, Ramadan Course)
- Daily curriculum section
- Class timings and announcements
- Contact information
- Fully responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Amiri, Playfair Display)

---

## 🚀 Run Locally

```bash
git clone https://github.com/Rifaqajmal/madrassa-website.git
cd madrassa-website
# open Madrasa-website.html in your browser
```
